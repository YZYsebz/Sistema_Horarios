```text
EXACTAMENTE 8 DÍGITOS
```

Todos deben ser numéricos.

Formato:

```text
YYGGNNNN
```

Donde:

```text
YY
=
últimos dos dígitos del año de ingreso

GG
=
número de generación

NNNN
=
cuatro dígitos aleatorios
```

Ejemplo:

```text

```

Interpretación:

```text
24
Año de ingreso 2024

24
Generación 24

0198
Segmento aleatorio
```

# 10. TIPO DE DATO DEL NÚMERO DE CONTROL

Aunque contenga únicamente números, NO utilizar:

```sql
INT
```

como tipo principal.

Utilizar preferentemente:

```sql
CHAR(8)
```

porque el número de control es un identificador y no un valor utilizado para operaciones matemáticas.

La columna deberá llamarse:

```text
cNumeroControl
```

por la convención definida anteriormente.

Crear una validación:

```sql
CHECK (
    LEN(cNumeroControl) = 8
    AND cNumeroControl NOT LIKE '%[^0-9]%'
)
```

Ajustar la sintaxis si resulta necesario.

# 11. GENERACIÓN DEL NÚMERO DE CONTROL

Para cada estudiante:

1. obtener año de ingreso;
2. tomar los últimos dos dígitos;
3. obtener generación;
4. convertir generación a dos dígitos;
5. generar cuatro dígitos aleatorios;
6. concatenar;
7. verificar que no exista;
8. insertar.

Ejemplo conceptual:

```text
2024
↓
24

Generación
24

Aleatorio
5831

Resultado
24245831
```

# 52. REGLA FINAL

Prioriza siempre:

```text
Integridad de datos
↓
3FN
↓
Seguridad
↓
Reglas de negocio
↓
Pruebas
↓
Backend
↓
Frontend
```

No sacrifiques integridad de la base de datos únicamente para generar más registros.

No rellenes catálogos artificialmente para alcanzar 50 registros.

Los datos sintéticos deben parecer académicamente razonables, pero deben identificarse claramente como datos de prueba.

Cuando la base haya pasado todas las validaciones, indica explícitamente:

```text
BASE DE DATOS LISTA PARA DESARROLLO
```

y entonces comienza la creación de la aplicación web.
